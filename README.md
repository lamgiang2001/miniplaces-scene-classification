# MiniPlaces scene classification

COSC 50523 Deep Learning Semester project: classify the MiniPlaces dataset of 128x128 images into the 100 scene
categories. 

# Dataset
The data for this task comes from the Places2 dataset, which is publicly available directly via the MIT CSAILVision repository. It contains 10+ million images belonging to 400+ unique scene categories. The challenge data will be a subset of the full Places2 dataset. 
The subset consists of 100,000 images for training, 10,000 images for validation, and 10,000 images for testing. 
Training, validation, and test splits are separated in distinct directory trees to prevent data leakage.
